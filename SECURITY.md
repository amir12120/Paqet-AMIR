# Security policy

## Supported versions

Only the latest release receives security fixes. Please update to it before reporting a problem.

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Report it privately on GitHub: open the **Security** tab of this repository and choose **Report a vulnerability**. Include:

- the panel version (shown on the panel's **Updates** page),
- the server's operating system and architecture,
- the steps to reproduce the problem and what an attacker could do with it.

Do not include real server addresses, passwords, tokens or keys; use placeholders.

You will get an answer as soon as possible. Once a fix is released, the release notes describe the problem.

# سیاست امنیتی

## نسخه‌های پشتیبانی‌شده

فقط آخرین نسخه به‌روزرسانی امنیتی می‌گیرد. لطفاً پیش از گزارش، به آن به‌روزرسانی کنید.

## گزارش آسیب‌پذیری

لطفاً برای مشکل امنیتی issue عمومی باز نکنید.

آن را به‌صورت خصوصی در گیت‌هاب گزارش کنید: در زبانهٔ **Security** همین مخزن، **Report a vulnerability** را بزنید و این‌ها را بنویسید:

- نسخهٔ پنل (در صفحهٔ **به‌روزرسانی** پنل)،
- سیستم‌عامل و معماری سرور،
- مراحل بازتولید مشکل و کاری که مهاجم با آن می‌تواند بکند.

نشانی واقعی سرور، گذرواژه، توکن یا کلید نفرستید؛ به‌جایشان مقدار نمونه بنویسید.

در اولین فرصت پاسخ داده می‌شود. پس از انتشار اصلاحیه، یادداشت‌های انتشار مشکل را شرح می‌دهند.
